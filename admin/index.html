חיבור ל-GitHub (פעם אחת)

כדי שהדף הזה יוכל להעלות שירים לאתר, הוא צריך מפתח גישה מהחשבון שלכם ב-GitHub. המפתח פותח רק את שני המאגרים של המשחק.

  1. פתחו את דף יצירת המפתח ב-GitHub (צריך להיות מחוברים לחשבון ).
  2. Token name: כתבו קלפי שירים. Expiration: בחרו כמה זמן המפתח יעבוד (למשל 366 days).
  3. Repository access: סמנו Only select repositories, לחצו על Select repositories ובחרו את ואת . ברירת המחדל (Public repositories) לא תעבוד.
  4. Permissions: לחצו + Add permissions, סמנו Contents, ואז בשורה של Contents שנו את Access: Read-only ל-Read and write.
  5. לחצו Generate token, העתיקו את המפתח (מתחיל ב-github_pat_) והדביקו אותו כאן:

המפתח נשמר רק בדפדפן הזה ונשלח רק ל-GitHub. אל תשתפו אותו עם אף אחד. אפשר לבטל אותו בכל רגע בהגדרות של GitHub.

לאיזה שיר זה הביצוע שלנו?

1

הוספת שירים

כאן רואים את השמות. באתר עצמו יש רק מספרים.
גררו לכאן קבצי שירים או תיקייה שלמה MP3, M4A, WAV, FLAC ועוד. כל שיר מומר ל-MP3 נקי, בלי שם ובלי תמונה. אחר כך מוסיפים לכל שיר גם את הביצוע שלנו.
הביצוע שלנו מוואטסאפשולחים הקלטה ישר מוואטסאפ, בלי להוריד אותה למחשב
  1. בטלפון (אנדרואיד) פותחים את הדף הזה ב-Chrome, מתחברים עם המפתח ומתקינים אותו כאפליקציה: בתפריט ⋮ בוחרים הוספה למסך הבית ואז התקנה. עושים את זה פעם אחת.
  2. בוואטסאפ לוחצים לחיצה ארוכה על ההקלטה, ואז ⋮ ← שיתוף.
  3. ברשימת האפליקציות בוחרים ניהול שירים.
  4. הדף נפתח עם ההקלטה. בוחרים לאיזה שיר היא שייכת, והיא נשמרת כביצוע שלנו.

באייפון אי אפשר לשתף ישר לאתר: בוואטסאפ שומרים את ההקלטה (שיתוף ← שמירה בקבצים), ואז בוחרים אותה ב"בחירת קובץ" בשורה של השיר.

מוכנים להעלאה

לכל שיר צריך גם את הביצוע שלנו: בוחרים קובץ או מקליטים כאן. בסריקה מתנגן קודם השיר המקורי ואחריו הביצוע שלנו.
